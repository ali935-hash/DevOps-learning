This module is part of my ongoing **Linux and Bash scripting learning journey**.

The purpose of this assignment was to develop practical Bash scripting skills by creating four scripts that demonstrate core concepts such as user input, arithmetic operations, file and directory management, permissions, conditional logic, timestamps, and automation.

---

## 📂 Scripts

### `calculatorscript.sh` — Basic Arithmetic Calculator

A Bash calculator that accepts two numbers from the user and performs addition, subtraction, multiplication, and division while handling division by zero.

### `fileoperations.sh` — File Operations

A Bash script that creates a directory and text file, writes information including the current date, and displays the file contents.

### `filechecker.sh` — File Checker & Permissions

A Bash script that checks whether a specified file exists and reports whether it has read, write, and execute permissions.

### `textfilebackup.sh` — Text File Backup

A Bash script that creates a timestamped backup directory and copies `.txt` files from a user-specified source directory while reporting the number of files backed up.
